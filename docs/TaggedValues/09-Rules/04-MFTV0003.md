---
title: "MFTV0003: Combine only values with the same tag"
description: The operands of an addition, the branches of a conditional expression, or the elements of a collection have different tags.
---

## Cause

Several values with different tags are combined into one value:

- the operands of `+` and `-`,
- the branches of `?:`, `??`, and switch expressions,
- the elements of arrays, collection expressions, and collection initializers.

<!-- ref:../../../samples/Meziantou.Framework.TaggedValues.Samples/Rules/CombinedValues.cs;region=TaggedValues_MFTV0003;format=md-fenced-code-block;dedent=true -->
```csharp
var id = useProject ? order.ProjectId : order.Id; // MFTV0003
Guid[] ids = [order.Id, order.ProjectId];         // MFTV0003
var length = meters + feet;                       // MFTV0003
```
<!-- endref -->

The arguments of `params` and the elements of a collection of `object` are not combined, as they hold values of
different kinds, such as the arguments of a log message.

## How to fix

Make every operand, branch, or element produce a value with the same tag:

<!-- ref:../../../samples/Meziantou.Framework.TaggedValues.Samples/Rules/CombinedValues.cs;region=TaggedValues_MFTV0003_Fixed;format=md-fenced-code-block;dedent=true -->
```csharp
var id = useProject ? order.ProjectId : project.Id; // both are ProjectIds
Guid[] ids = [order.Id, other.Id];                  // both are OrderIds
```
<!-- endref -->

When the values are right, fix the [\[ValueTag\]](cref:Meziantou.Framework.TaggedValues.ValueTagAttribute) of the declaration that is tagged incorrectly. When a declaration
legitimately holds both kinds of values, give it both tags: `[ValueTag("OrderId", "ProjectId")]`.
