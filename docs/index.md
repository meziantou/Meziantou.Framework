Meziantou.Framework is a collection of .NET libraries and tools. They cover ASP.NET Core, testing, file formats,
networking, imaging, text processing and more. Each library is its own NuGet package, so you install only the ones
you use. When a package depends on others from the collection, NuGet installs them for you: see
[Package dependencies](PackageDependencies.md).

Pick a library below. Each section starts with an introduction to what the library does and a getting-started page
that installs it and runs a first example. Then come pages for each task. The pages link to the API reference for
the types and members they use.

The libraries are open source under the MIT license. The source code, the issue tracker and the releases are on
[GitHub](https://github.com/meziantou/Meziantou.Framework).
