# Meziantou.Framework.JavaScriptEngine

An ECMAScript engine written in .NET: a hand-written parser, a bytecode compiler and an interpreter. It is validated by
[test262](https://github.com/tc39/test262), the conformance suite of ECMAScript.

The engine is under development: see [the test262 results](../../tests/Meziantou.Framework.JavaScriptEngine.Test262/summary.md).
