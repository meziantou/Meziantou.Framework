# Meziantou.Framework.Pdf.Rendering

The renderer of the pages of `Meziantou.Framework.Pdf` documents: a content stream interpreter that draws on the
`DrawingCanvas` of `Meziantou.Framework.Imaging`.

These instructions complete the repository-level `AGENTS.md` and the ones of `Meziantou.Framework.Pdf`. The user guide
is [readme.md](readme.md): keep the code, the XML documentation and `readme.md` consistent in the same change.

## Hard constraints

- **Clean room**, as `Meziantou.Framework.Pdf`: write the code from ISO 32000-2, the Adobe technical notes (Type 1,
  CFF, Type 2 charstrings) and the specifications they reference. PDFium, pdf.js, Poppler and MuPDF are test oracles
  only: never copy or port their code. Cite the clause in the comments of the code that implements it.
- Fully managed and trimmable. The dependencies are `Meziantou.Framework.Pdf`, `Meziantou.Framework.Imaging` and
  `Meziantou.Framework.Fonts`, with exact versions (`UseExactProjectReferenceVersions`): the renderer uses their
  internal types through `InternalsVisibleTo` (the content stream reader and the font decoders of Pdf, the CFF and glyf
  readers of Fonts).
- `DrawingCanvas` is a `ref struct`: the canvas is a parameter of the methods that draw, never a field; the callbacks
  of `Clip`, `Layer`, `Mask` and `Filter` receive the canvas they draw on.
- **Bounded work.** Every operator, glyph, image and shading is charged to `PdfRenderOptions.MaxOperations`
  (`RenderCache.Charge`); the nesting of forms, patterns, Type 3 glyphs and soft masks is limited (`MaxDepth`), as are
  the pixels of images and shadings, the meshes and the clips. The errors of the content are skipped where they occur
  (`RenderCache.IsContentError`): a damaged object does not stop the page.
- **Bundled fonts** (`Fonts/Substitution/`): the Liberation fonts (SIL Open Font License 1.1) are generated by
  `dotnet run eng/pdf/update-substitution-fonts.cs` from the pinned release; never edit them by hand. Keep
  `THIRD-PARTY-NOTICES.md` in sync with them.
- **Bounded layers.** A drawing is clipped to the pixels it can change before the clip, the soft mask and the blend
  mode of the graphics state are applied (`PaintWithState` with bounds): the layers of the canvas are as large as the
  clip they are created in.

## Tests

- `tests/Meziantou.Framework.Pdf.Rendering.Tests`: the pixels of small documents built with the content builder.
- `tests/Meziantou.Framework.Pdf.Corpus` (`PdfJsRenderedPages`): the pages of the reference tests of pdf.js are
  rendered at 36 dpi and compared with PDFium (`pdfium_test` of the Meziantou.Prebuilt release). The pages that differ
  by more than 5% of their pixels are recorded in `expectations/rendering.txt`; run the test on Windows with
  `PDF_UPDATE_EXPECTATIONS=1` (one target framework) to record them.
