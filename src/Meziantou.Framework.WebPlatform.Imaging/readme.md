# Meziantou.Framework.WebPlatform.Imaging

Rasterizes the documents of [Meziantou.Framework.WebPlatform](../Meziantou.Framework.WebPlatform/readme.md) with the fully
managed drawing API of [Meziantou.Framework.Imaging](../Meziantou.Framework.Imaging/readme.md) (a `RenderingBackend`):
screenshots of the pages and of the elements, 2D canvases, image decoding and encoding.

See [rendering.md](../Meziantou.Framework.WebPlatform/docs/rendering.md).
