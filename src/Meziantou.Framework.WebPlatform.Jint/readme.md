# Meziantou.Framework.WebPlatform.Jint

Runs the scripts of the documents of [Meziantou.Framework.WebPlatform](../Meziantou.Framework.WebPlatform/readme.md) with
the [Jint](https://github.com/sebastienros/jint) JavaScript engine: a `ScriptEngine` with the WebIDL bindings of the DOM.

See [scripting.md](../Meziantou.Framework.WebPlatform/docs/scripting.md) for the threat model and the options.
