# Hyphenation dictionaries

The dictionaries of this folder (`*.hyph`) are embedded in the library: `HyphenationDictionary` uses them for the automatic hyphenation
of `hyphens: auto` (see [layout.md](../../../../docs/layout.md#line-breaking)). They are generated by `tools/Meziantou.Framework.WebPlatform.SpecGen`
(`HyphenationGenerator`) from the hyphenation patterns of [hyph-utf8](https://github.com/hyphenation/tex-hyphen)
(`tests/Meziantou.Framework.WebPlatform.SpecData/hyphenation`, pinned in `tests/Meziantou.Framework.WebPlatform.SpecData/versions.json`), the source of the dictionaries of Chrome on Android, Linux
and ChromeOS and of Firefox. Do not edit them: update the source and run `dotnet run --project tools/Meziantou.Framework.WebPlatform.SpecGen`.

Each file is a packed trie of the patterns and the exceptions of a language (Liang's algorithm), compressed with Brotli:
about 470 KB for the 46 dictionaries (bn uses the file of as, and mr the file of hi: their patterns are the same). A
dictionary is loaded on first use (about 1 ms for the largest ones: de-1996, de-ch-1901, nb, nn and af).

The names are the locales of the dictionaries of Chrome (`el` is `hyph-el-monoton`; `sr-cyrl` and `sr-latn` are the
Serbo-Croatian patterns `hyph-sh-cyrl` and `hyph-sh-latn`). [LICENSES.txt](LICENSES.txt) has the copyright and license
notices of the source files (MIT, BSD, LPPL, the Unlicense, or permissive notices; the patterns dual-licensed with the GPL or
the LGPL are used under their permissive license). The patterns available only under copyleft licenses are not included:
Czech (`hyph-cs`, GPL), Hungarian (`hyph-hu`, MPL 1.1/GPL/LGPL), Armenian (`hyph-hy`, LGPL), Latvian (`hyph-lv`, LGPL/GPL)
and Serbian (`hyph-sr-cyrl`, GPL). The Ethiopic patterns (`hyph-mul-ethi`, 455 letters) do not fit the format (at most 254
letters), and the German 1901 orthography (`hyph-de-1901`) is not included.
