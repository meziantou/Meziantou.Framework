# Word lists and phrase model

The data of this folder is used by the line breaking (see [layout.md](../../../../docs/layout.md#line-breaking)):

- `*.dict`: the word lists of the Southeast Asian scripts that write no space between the words (Thai, Lao, Burmese,
  Khmer), embedded in the library: `SoutheastAsianWordBreaker` segments the runs of their letters into words (the lexical
  word breaking of CSS Text). Each file is a trie of the words, compressed with Brotli: about 570 KB for the four lists
  (Thai 69 KB, Lao 89 KB, Burmese 146 KB, Khmer 262 KB). A list is loaded on first use of its script.
- `JapanesePhraseBreaker.Model.g.cs`: the model of the phrase segmentation of Japanese (`word-break: auto-phrase` and
  `word-space-transform: auto-phrase`), about 1,400 scores.

They are generated by `tools/Meziantou.Framework.WebPlatform.SpecGen` (`SegmentationGenerator`) from the data of [ICU](https://github.com/unicode-org/icu)
(`tests/Meziantou.Framework.WebPlatform.SpecData/icu`, pinned in `tests/Meziantou.Framework.WebPlatform.SpecData/versions.json`), the line breaking of Chrome: the word lists of
`icu4c/source/data/brkitr/dictionaries` and the model `icu4c/source/data/brkitr/adaboost/jaml.txt` (a model of
[BudouX](https://github.com/google/budoux)). Do not edit them: update the source and run `dotnet run --project tools/Meziantou.Framework.WebPlatform.SpecGen`.
`SoutheastAsianWordBreaker` and `JapanesePhraseBreaker` are ports of the break engines of ICU (`dictbe.cpp`, `mlbe.cpp`).

Burmese word lists) and the headers of the source files with their copyright notices.
