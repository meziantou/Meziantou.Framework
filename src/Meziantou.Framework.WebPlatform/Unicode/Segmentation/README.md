# Phrase model

The data of this folder is used by the line breaking (see [layout.md](../../../../docs/layout.md#line-breaking)):
`JapanesePhraseBreaker.Model.g.cs` is the model of the phrase segmentation of Japanese (`word-break: auto-phrase` and
`word-space-transform: auto-phrase`), about 1,400 scores.

It is generated by `tools/Meziantou.Framework.WebPlatform.SpecGen` (`SegmentationGenerator`) from the data of [ICU](https://github.com/unicode-org/icu)
(`tests/Meziantou.Framework.WebPlatform.SpecData/icu`, pinned in `tests/Meziantou.Framework.WebPlatform.SpecData/versions.json`), the line breaking of Chrome: the model
`icu4c/source/data/brkitr/adaboost/jaml.txt` (a model of [BudouX](https://github.com/google/budoux)). Do not edit it:
update the source and run `dotnet run --project tools/Meziantou.Framework.WebPlatform.SpecGen`. `JapanesePhraseBreaker`
is a port of the machine learning break engine of ICU (`mlbe.cpp`).

The words of the Southeast Asian scripts that write no space between the words (Thai, Lao, Burmese, Khmer) are found
with the word lists and the dictionary break engines of ICU of the Meziantou.Framework.Unicode.Dictionaries package.

copyright notice.
