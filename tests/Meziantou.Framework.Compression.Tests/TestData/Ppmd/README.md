# PPMd test data

The inputs are generated, so they carry no third-party content:

- `text.bin`: 4,000 bytes of pseudo-English text, generated from a fixed word list with an xorshift32 generator (seed 7).
- The "two-letters" input is generated by the tests (`Ppmd7Tests.CreateTwoLetterData`): random `a` and `b` (xorshift32,
  seed 3), 20,000 bytes for the 7z streams and 50,000 bytes for the zip streams. It compresses little and creates many
  contexts, so it fills the memory of the model: the 7z stream restarts the model, and the zip streams restore it with both
  methods.

The compressed files were made with 7-Zip 26.06 (`7zz`), except `text-o6.ppmd7a`:

| File | Format | Command |
| --- | --- | --- |
| `text-o6.ppmd7` | 7z PPMd (order 6, 64 KiB) | `7zz a -t7z -mhc=off -m0=PPMd:o=6:mem=16m` (7-Zip reduces the memory to the input size) |
| `text-o2.ppmd7` | 7z PPMd (order 2, 64 KiB) | `7zz a -t7z -mhc=off -m0=PPMd:o=2:mem=64k` |
| `ab-o32-restart.ppmd7` | 7z PPMd (order 32, 64 KiB) | `7zz a -t7z -mhc=off -m0=PPMd:o=32:mem=64k` |
| `text-o8.ppmd8` | zip method 98 (order 8, 1 MiB, restart) | `7zz a -tzip -mx=5 -mm=PPMd:o=8:mem=1m` |
| `ab-o16-restart.ppmd8` | zip method 98 (order 16, 1 MiB, restart) | `7zz a -tzip -mx=5 -mm=PPMd:o=16:mem=1m` |
| `ab-o16-cutoff.ppmd8` | zip method 98 (order 16, 1 MiB, cut off) | `7zz a -tzip -mx=9 -mm=PPMd:o=16:mem=1m` (7-Zip cuts the model off from level 7) |
| `text-o6.ppmd7a` | RAR 2.9/4.x PPMd block (order 6, 1 MiB) | The test range encoder of `PpmdRarTests` |

Layout of the files:

- `.ppmd7`: the 5 bytes of the 7z coder properties (order, memory size as a little-endian UInt32), then the packed stream
  (offset 32 of the archive, up to the next header).
- `.ppmd8`: the data of the zip entry: 2 little-endian bytes (order - 1 in bits 0-3, memory size in MiB - 1 in bits 4-11,
  restore method in bits 12-15), then the PPMd stream, which ends with an end marker.
- `.ppmd7a`: the order, the memory size in MiB minus one, then the stream (no end marker).

The fuzz targets of `fuzz/Meziantou.Framework.Compression.Fuzz` use these files as seeds, with the same layouts.
