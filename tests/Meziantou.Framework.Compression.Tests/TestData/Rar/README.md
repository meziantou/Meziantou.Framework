# RAR test files

Nobody but RARLAB can create RAR archives, so the test files come from the test suites of two other RAR readers.
They are copied unchanged (the libarchive files are uudecoded); only their names are changed.

- `libarchive-*`: [libarchive](https://github.com/libarchive/libarchive), commit [`e45f868d3da2b2bf104ae85bc1783e1eeb4ac940`](https://github.com/libarchive/libarchive/tree/e45f868d3da2b2bf104ae85bc1783e1eeb4ac940/libarchive/test), file `libarchive/test/test_read_format_<name>.rar.uu` where `<name>` is the name of the file without the prefix, with `-` replaced by `_`. BSD-2-Clause license, see [LICENSE-libarchive.txt](LICENSE-libarchive.txt).
- `rarfile-*`: [rarfile](https://github.com/markokr/rarfile), commit [`d2f7df6fc843dae356fd6b0a85971dc36fd6e757`](https://github.com/markokr/rarfile/tree/d2f7df6fc843dae356fd6b0a85971dc36fd6e757/test/files), file `test/files/<name>.rar` where `<name>` is the name of the file without the prefix. ISC license, see [LICENSE-rarfile.txt](LICENSE-rarfile.txt).

`expected.json` is the output of `unrar lta` (unrar 7.23, `TZ=UTC`) for each archive (the first volume of a multi-volume archive), and the SHA-256 of the files `unrar x -ver` extracts.
