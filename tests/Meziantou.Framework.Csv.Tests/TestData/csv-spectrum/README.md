# csv-spectrum

Offline fixtures from https://github.com/max-mapper/csv-spectrum/tree/d30e80f8b99d2eecb3778f1d7b9ed1cb425502ec (v2.0.0), licensed under BSD-2-Clause; see LICENSE.txt.

cases.json contains every file of `csvs/`: its name, the CSV text, and the expected objects of the JSON file of the same name in `json/`. The first row of each file is a header row. These fixtures are independent expected parser results, not outputs generated by this library. `Meziantou.Framework.Csv.Fuzz` embeds the same file as seeds.

The repository has no license file: the license is the `license` field of its `package.json`, whose `author` is the copyright holder in LICENSE.txt.

To refresh, clone the repository at the new commit, and for each `csvs/<name>.csv` write its name, its text as `csv`, and the parsed `json/<name>.json` as `expected`.
