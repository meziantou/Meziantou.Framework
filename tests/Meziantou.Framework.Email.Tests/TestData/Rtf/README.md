# RTF test files

`ms-oxrtfex-example.rtf` is the example of section 3.1 ("Encapsulating HTML into RTF") of [MS-OXRTFEX], revision 15.0 of
2025-05-20: the RTF of an HTML document encapsulated in RTF. The Open Specifications documentation lets implementers copy
it to develop implementations of the format. `RtfEncapsulationTests` checks the HTML extracted from it.

[MS-OXRTFEX]: https://learn.microsoft.com/openspecs/exchange_server_protocols/ms-oxrtfex
