# Map bundle fixtures

`Switzerland/` is a map bundle built by `src/Meziantou.Framework.Geo.Maps.Tool`
(`build --region switzerland`), used by the tests of `Meziantou.Framework.Geo.Maps` and `Meziantou.Framework.Charts`.

- The borders and the cantons are derived from OpenStreetMap through country-levels: © OpenStreetMap contributors,
  available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/).
- The cities, rivers, lakes and physical regions come from [Natural Earth](https://www.naturalearthdata.com/) (public domain).

Rebuild it with the tool after a change of the format or of the sources.
