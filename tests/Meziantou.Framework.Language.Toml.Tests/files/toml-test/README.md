# toml-test

Offline fixtures from https://github.com/toml-lang/toml-test/tree/ce08da1ddb075d1c7596d663c7fcba9a2ae02c5c (v2.2.0), licensed under MIT; see LICENSE.txt.

cases.json contains every case listed in `tests/files-toml-1.0.0` and `tests/files-toml-1.1.0`: its name, the versions that list it, the TOML text (or `tomlBase64` when the file is not valid UTF-8), and for a valid case the expected tagged JSON. These fixtures are independent expected parser results, not outputs generated by this library.

To refresh, clone the repository at the new tag and rerun the conversion: read both file lists, and for each `.toml` file write its name, versions, text, and (for `valid/`) the parsed `.json` next to it.
