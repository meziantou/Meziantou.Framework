# YAML test suite

Offline fixtures from https://github.com/yaml/yaml-test-suite/tree/6ad3d2c62885d82fc349026c136ef560838fdf3d (data branch), licensed under MIT; see LICENSE.txt.

cases.json contains all 402 in.yaml, test.event, === and error records. Input and event strings are preserved (event trailing line breaks are removed). The upstream case ID is retained for diagnosis. These fixtures are independent expected parser results, not outputs generated by this library. Tests run both the string and buffered TextReader parser paths.
