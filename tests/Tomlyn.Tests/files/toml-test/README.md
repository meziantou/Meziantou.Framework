# toml-test

Offline fixtures from https://github.com/toml-lang/toml-test/tree/74eb956a42e575b17406f4f0c82ebefca011f2bc (v2.0.0), licensed under MIT; see LICENSE.txt. This is the version the Tomlyn test suite was written against.

cases.json contains every `.toml` file under `tests/`: its name (the path relative to `tests/`, without the extension), the TOML text (or `tomlBase64` when the file is not valid UTF-8), and for a valid case the expected tagged JSON from the `.json` file next to it. These fixtures are independent expected parser results, not outputs generated by this library.

To refresh, clone the repository at the new tag and rerun the conversion: for each `tests/**/*.toml` file, write its name, its text, and (for `valid/`) the parsed `.json` next to it.
